# MSP checklist v2026.10.06 fallback copy

This directory retains a byte-identical fallback copy of the approved MSP checklist release from
`AMB-canonical/checklists/msp-conformance/v2026.10.06/`.

`AMB-canonical` remains the authority and normal audit source. Use this copy only when a team member
cannot locate or access that checkout. Before use, verify it from this directory:

```bash
sha256sum --check SHA256SUMS
```

The checklist is immutable: do not edit it and do not create a moving `latest` alias. A future
approved version must be added in its own versioned directory through an OpenSpec-governed change.
The external pinned canonical claim closure remains required to issue compliance verdicts.
